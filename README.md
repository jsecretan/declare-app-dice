# Dice

Big dice to throw — d4 through d20, with a running total.

A [Declare](https://davidtemkin.github.io/declarelang/) app for
[Declare Hub](https://github.com/jsecretan/declare-hub). `declare-app.json`
says how the hub shows it (title, icon, window size) and which file to run.

Fork it to make it your own: in the hub, ask the app's ✦ assistant for a
change and the hub forks it for you; ⑂ on its window lists everyone else's
forks to try.
